Atividade Git e GitHub

Sobre o projeto

Este projeto foi desenvolvido como parte de uma atividade acadêmica sobre Git e GitHub.

Objetivos

  • Aprender conceitos básicos de Git e GitHub;
  • Utilizar o GitHub Desktop;
  • Praticar o controle de versões;
  • Utilizar o Live Server;
  • Aplicar Conventional Commits.

Ferramentas utilizadas

  • Git
  • GitHub
  • GitHub Desktop
  • Visual Studio Code
  • Live Server
  • Inteligência Artificial

Projeto desenvolvido para fins acadêmicos.
