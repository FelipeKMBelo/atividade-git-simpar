# Atividade Git e GitHub

## Descrição

Este repositório foi criado para a realização da atividade prática sobre Git e GitHub, envolvendo o gerenciamento de versões, documentação de projetos e utilização de ferramentas de desenvolvimento.

A atividade também aborda o uso do GitHub Desktop, Visual Studio Code, Live Server, Conventional Commits e ferramentas de Inteligência Artificial como apoio ao desenvolvimento.

## Objetivos

- Compreender o funcionamento básico do Git e do GitHub;
- Praticar a criação, clonagem e atualização de um repositório;
- Utilizar o GitHub Desktop para gerenciamento das alterações;
- Utilizar o Visual Studio Code para edição dos arquivos;
- Executar uma página HTML utilizando o Live Server;
- Aplicar o padrão Conventional Commits na criação das mensagens de commit;
- Utilizar Inteligência Artificial como apoio na descrição das alterações realizadas.

## Como clonar o projeto

Para obter uma cópia local deste repositório, utilize a opção de clonagem do GitHub ou do GitHub Desktop.

Após clonar o projeto, abra a pasta no Visual Studio Code para visualizar e editar seus arquivos.

## Como utilizar

O projeto será desenvolvido gradualmente durante a realização da atividade.

Os arquivos podem ser editados no Visual Studio Code e as alterações podem ser acompanhadas pelo GitHub Desktop antes de serem registradas no histórico do projeto.

Quando houver uma página HTML, ela poderá ser executada localmente utilizando o Live Server.

## Controle de versões

As alterações realizadas no projeto serão registradas por meio de commits.

As mensagens dos commits seguirão o padrão Conventional Commits, utilizando prefixos como:

- `docs:` para alterações na documentação;
- `feat:` para novas funcionalidades;
- `refactor:` para reorganização ou melhoria do código sem alteração da funcionalidade.

## Contribuição

Este repositório faz parte de uma atividade acadêmica. As alterações são realizadas de acordo com as etapas propostas na atividade e registradas no histórico do Git.
